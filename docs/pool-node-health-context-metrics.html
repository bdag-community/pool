Pool Node Health Context Metrics

This feature makes the pool consume richer getTemplateHealth context from the node and expose it as Prometheus metrics. It is intentionally observe-only: routing remains based on the existing mineable, submit-ready, template-available, and template-age gates.

Why This Exists

The watchdog and dashboards currently infer too much from submit failures and logs. The node now knows more about template build age, pending template refreshes, and P2P freshness. The pool should become the stable integration point for that context so downstream tooling does not duplicate node probing.

What Changes

  • Decode passive node health fields from getTemplateHealth.
  • Store the fields in the backend snapshot for inspection and future APIs.
  • Publish backend-labeled gauges for template build, pending refresh, and P2P freshness state.

What Does Not Change

  • No live mining service restart is required by this source change.
  • No dashboard or watchdog behavior changes are included here.
  • No pool start, template, or submit decision uses the new advisory fields yet.

Metrics Added

  • pool_rpc_backend_node_health_last_template_build_age_seconds
  • pool_rpc_backend_node_health_last_template_build_duration_seconds
  • pool_rpc_backend_node_health_last_template_build_error_blocking
  • pool_rpc_backend_node_health_pending_template_build
  • pool_rpc_backend_node_health_pending_template_build_priority
  • pool_rpc_backend_node_health_p2p_mining_fresh
  • pool_rpc_backend_node_health_p2p_consensus_peer_count
  • pool_rpc_backend_node_health_p2p_fresh_consensus_peer_count
  • pool_rpc_backend_node_health_p2p_stale_consensus_peer_count
  • pool_rpc_backend_node_health_p2p_best_peer_lead_blocks
  • pool_rpc_backend_node_health_p2p_graph_state_age_seconds with kind values best, avg, max, and sync_peer.

Review Guardrail

This branch must not make pending_template_build, p2p_mining_fresh, or template build latency affect backend health. Those fields are for visibility first. Any future routing decision should be a separate feature with live A/B gates.
